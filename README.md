Employee Data Sorting Using Pandas

About the Project

This project demonstrates how to sort an employee dataset using Python and Pandas. It includes sorting employee details by salary, age, and department.

Objective

To understand how to sort data in ascending and descending order and how to sort a dataset using multiple columns.

Technologies Used

- Python
- Pandas
- Jupyter Notebook

Dataset Details

The dataset contains the following employee information:

- Name
- Age
- Department
- Salary

Operations Performed

1. Created an employee dataset using a Python dictionary.
2. Converted the data into a Pandas DataFrame.
3. Sorted employees by salary in ascending order.
4. Sorted employees by salary in descending order.
5. Sorted employees by department and salary.
6. Sorted employees by age in descending order.

Python Functions Used

- "pd.DataFrame()" – Creates a DataFrame from the employee data.
- "sort_values()" – Sorts the dataset based on one or more columns.
- "ascending=False" – Sorts values in descending order.

How to Run the Project

1. Install Python on your computer.

2. Install Pandas using the command:
   
   pip install pandas

3. Open Jupyter Notebook or your preferred Python editor.

4. Copy the Python program into a new file or notebook.

5. Run the program to view the sorted employee data.

Learning Outcomes

- Learned how to create a DataFrame using Pandas.
- Understood ascending and descending sorting.
- Practised sorting data using multiple columns.
- Improved basic data manipulation skills in Python.

Conclusion

This project helped me understand how to organize and analyze employee data using Pandas sorting methods. These techniques are useful when working with real-world datasets.
